## 이렇게 공부해요

1. **영상을 틀고**, 같은 주의 **수업 노트북**을 Colab에서 같이 열어요. 설치는 필요 없고, 구글 계정만 있으면 돼요.
2. 영상에 코드가 나오면 **빈 코드 칸에 똑같이 쳐서** 실행해요. 결과가 영상과 같으면 성공!
   막히거나 결과가 다르면 **수업 완성본**과 비교해 봐요.
3. 노트북 맨 아래 **과제**와 **오답노트**를 해요.
4. **문제집**을 풀고 **정답과 풀이**로 맞춰 봐요.
5. 헷갈리면 **수업자료 PDF**로 복습!

## 처음이라면 꼭 읽어 주세요

| 이럴 때 | 이렇게 해요 |
|---|---|
| 셀을 실행하고 싶어요 | 셀을 누르고 **Shift+Enter**. 태블릿·폰이라면 셀 왼쪽의 **▶ 버튼** |
| "Google 로그인 필요" 창이 떠요 | 구글 계정으로 로그인하면 돼요 |
| "경고: 이 노트북은 Google에서 작성하지 않았습니다" 창이 떠요 | 이 저장소의 노트북이라면 **무시하고 계속하기**. 모르는 사람이 만든 노트북이라면 먼저 코드를 읽어 보세요 |
| 고친 내용을 남기고 싶어요 | **파일 → Drive에 사본 저장**. 내 구글 드라이브에 저장돼요 |
| 빨간 글씨(오류)가 나와요 | 겁먹지 말고 **맨 마지막 줄**부터 읽어요 |
